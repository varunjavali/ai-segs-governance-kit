# Decisions

- `project-profile.md` - written by `scripts/wizard.py`; wizard answers and assumptions (proposals until the gate is signed in `docs/governance/gate-log.md`).
- Architecture decisions: `docs/architecture/adr/`.
- Scope changes: `docs/roadmap/mvp-roadmap.md` change log and `templates/change-request.md`.
- Exceptions: `templates/exception-request.md` and `docs/registers/risk-log.md`.

Rule: a decision exists only when a named human approved it. Assumptions are listed with the gate that must confirm them.
